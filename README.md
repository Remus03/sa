# Laborator Sisteme Autonome

## Punctaj Proiect 
* EKF/Metoda de localizare locala
* ICP/Odometrie LiDAR sau vizuala
* Particle Filter/localizare globala
* Generare de traiectorie
* Controller
* Behaviour Tree/ Behaviour model

Punctaj total: 30p.
Fiecare componenta valoreaza 5p, din care 3p este implementarea si 2p proba practica.
Puncajul complet de 3p este acordat pentru o implementare de la 0. Implementarea folosind pachete ROS existente ofera 1.5p.
